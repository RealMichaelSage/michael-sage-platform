## 1. Концепция и Разделение Сущностей

Блог и База Знаний решают принципиально разные задачи, но работают в единой конверсионной связке:

```
                       +-----------------------------------------+
                       |          https://a-sage.ru              |
                       +--------------------+--------------------+
                                            |
                    +-----------------------+-----------------------+
                    |                                               |
                    v                                               v
     +-----------------------------+                 +-----------------------------+
     |       БЛОГ (/blog)          |                 |   БАЗА ЗНАНИЙ (/knowledge)   |
     +-----------------------------+                 +-----------------------------+
     | • Смыслы, тренды, визионерство|               | • Интерактивные калькуляторы|
     | • Большие лонгриды и кейсы  |                 | • Каталог AI-Скиллов (GitHub)|
     | • Мышление фаундера         |                 | • Бесплатные продукты (SageMeet)
     | • Входная воронка и SEO     |                 | • Сниппеты встройки (UTM, etc)|
     |                             |                 | • Реестр MCP серверов       |
     |                             |                 | • Обучающие видео и воркшопы|
     +--------------+--------------+                 +--------------+--------------+
                    |                                               |
                    +-----------------------+-----------------------+
                                            |
                                            v
                    +-----------------------------------------+
                    |      КОНВЕРСИЯ В ПРОДУКТЫ И КЛУБ        |
                    |  (Клуб Tribute · Трекинг · Менторинг)   |
                    +-----------------------------------------+
```

### Сравнительная матрица:

| Параметр | 📝 Блог (`/blog`) | 🧠 База Знаний (`/knowledge`) |
| :--- | :--- | :--- |
| **Главная цель** | Привлечь внимание, доказать глубокую экспертизу, сформировать доверие, раскрыть методологию. | Дать моментальную прикладную пользу: интерактивный расчет, готовый код, репозиторий, MCP-конфиг. |
| **Формат контента** | Статьи, аналитические эссе, пошаговые кейсы, разборы трендов (1500–4000 слов). | Интерактивные UI-калькуляторы, карточки скиллов со ссылками на GitHub, видеоплеер, код-сниппеты. |
| **Поведение читателя** | Вдумчивое чтение, шеринг в соцсетях и Telegram. | Рабочий инструментарий: «посчитал ➔ скопировал ➔ скачал ➔ внедрил за 5 минут». |

## 2. Архитектура Блога (`/blog`)

### 2.1. Рубрикатор статей (4 ключевых потока):
1. **`// VIBE CODING & РАЗРАБОТКА`**
   - Скоростная разработка сервисов без раздутых бюджетов и многомесячных согласований.
   - Стек инструментов (Claude Code, Cursor, Antigravity, Supabase, Next.js, Nginx).
   - Как фаундеру без навыков программирования собрать работающий MVP за 3 дня.
2. **`// ПРИКЛАДНЫЕ ИИ-АГЕНТЫ`**
   - Автономные конвейеры (генерация медиа, автодокументооборот, парсинг данных).
   - Интеграция LLM с CRM-системами (Bitrix24 / amoCRM) и Telegram-мостами.
   - Разбор реальных сценариев роботизации отделов продаж и клиентской поддержки.
3. **`// ТРЕКИНГ & ВЕНЧУР`**
   - Выход из операционки: как перестать тушить пожары и заняться масштабированием.
   - Теория ограничений (TOC) Голдратта в малом и среднем бизнесе.
   - Подготовка стартапа к инвестициям: метрики, питч-деки, воронка инвесторов.
4. **`// КЕЙСЫ & РАЗБОРЫ ОШИБОК`**
   - Анатомия запуска проектов (`aipsy.press`, `picozon.pro`, `maikers.pro`).
   - Разборы реальных бизнес-ситуаций клиентов (с цифрами до/после).

### 2.2. Интерфейс страницы статьи:
- **Содержание (Table of Contents):** Плавающее боковое меню (Scrollspy).
- **Типографика:** Space Grotesk + JetBrains Mono для сниппетов.
- **Инлайн-лидмагнит:** Баннер в середине или конце статьи с выходом на Клуб / Диагностику.

## 4. Детальное Описание Новых Модулей Базы Знаний

### 4.1. Модуль «Интерактивные Калькуляторы»
- **Принцип работы:** Мгновенный пересчет параметров в браузере (Client-side JS на чистом Web API без тяжелых библиотек).
- **Калькулятор Unit-экономики:**
  - Входные данные: Трафик, Конверсия лендинга (C1), Стоимость лида (CPL), Конверсия в оплату (C2), Средний чек (AOV), Себестоимость (COGS), Постоянные расходы (Fixed Costs).
  - Выходные данные: Стоимость привлечения клиента (CAC), Пожизненная ценность (LTV), Соотношение LTV/CAC, Чистая прибыль, Точка безубыточности (в сделках и рублях).
  - Экспорт: Кнопка *«Скопировать расчет в буфер»* и *«Скачать PDF-отчет»*.
- **Калькулятор налога и наценки:**
  - Вход: Себестоимость товара/услуги, желаемая маржа или наценка %, режим налогообложения (УСН 6%, УСН 15%, НПД 4/6%, Патент, НДС).
  - Выход: Итоговая розничная цена, сумма налога к уплате, чистая прибыль после всех вычетов.

### 4.2. Модуль «База AI-Скиллов (GitHub)»
- **Карточка скилла:**
  - Название (например, `ai-sales-negotiator`, `seo-ops`, `beget-aisage-deploy`, `yandex-metrika-ops`).
  - Поддерживаемые платформы: `[Claude Code]`, `[Antigravity]`, `[Cursor]`, `[Roo Code]`.
  - Описание сценария: какую рутину автоматизирует скилл.
  - Кнопка: **`Открыть на GitHub ↗`** + блок команды для быстрой установки в терминале (`git clone ...`).

### 4.3. Модуль «База бесплатных продуктов (SageMeet & Co)»
- Каталог готовых утилит и сервисов Михаила Пузырёва:
  - **SageMeet:** Автоматический ассистент онлайн-встреч (подключение к звонку, запись, выделение договоренностей, постановка задач в CRM).
  - **@TLDRVoiceBot:** Быстрая суммаризация голосовых сообщений.
  - **VibeCode Boilerplate:** Чистый стартовый шаблон для быстрой сборки и деплоя статических сайтов на Beget / VPS.

### 4.4. Модуль «База кодов для встройки на сайт»
- Библиотека готовых проверенных JS/CSS сниппетов:
  - **UTM Auto-Capture & Preserve:** Скрипт, который автоматически ловит все метки `utm_source`, `utm_medium`, `utm_campaign`, `utm_content`, `utm_term`, `gclid`, `yclid`, сохраняет их в `sessionStorage` и автоматически проставляет во все скрытые инпуты любых форм на сайте, даже если пользователь переходил по разным внутренним страницам.
  - **Anti-Bot Honeypot:** Невидимая ловушка для спам-ботов.
  - **Yandex Metrika Zero-Lag:** Скрипт подключения счетчика без влияния на оценку PageSpeed.

### 4.5. Модуль «База MCP с настройками»
- Готовые конфигурации Model Context Protocol:
  - Конфиги для интеграции LLM с **Telegram Bot API**, **GitHub**, **Supabase PostgreSQL**, **Яндекс Метрикой**, **Google Calendar**, **Битрикс24**.
  - Шаблоны `.env.example` и готовый JSON-блок для вставки в настройки IDE.

### 4.6. Модуль «Обучающие видео и воркшопы»
- Встроенные плееры (VK Видео / YouTube / Rutube / Kinescope).
- Структурированные таймкоды по минутам.
- Под видео: список прикрепленных ссылок на код, промпты и статьи из Блога.

## 6. Технические Принципы Реализации

1. **Максимальная производительность:** Никаких тяжелых фреймворков. Калькуляторы работают на чистом Vanilla JS, моментальный отклик 0ms.
2. **SEO & GEO Индексация:** Каждый калькулятор, скилл и видео получают отдельные человекопонятные URL (`/knowledge/calculators/unit-economics`, `/knowledge/skills/seo-ops`) и Schema.org разметку `SoftwareApplication` / `HowTo` / `VideoObject`.
3. **1-Click UX:** Все промпты, конфиги MCP и коды снабжены кнопками копирования в буфер обмена с визуальным фидбеком.
