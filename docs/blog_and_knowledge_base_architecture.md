## 1. Концепция и Разделение Сущностей

Блог и База Знаний решают принципиально разные бизнес-задачи, но работают в единой конверсионной синергии:

```
                       +-----------------------------------------+
                       |          https://a-sage.ru              |
                       +--------------------+--------------------+
                                            |
                    +-----------------------+-----------------------+
                    |                                               |
                    v                                               v
     +-----------------------------+                 +-----------------------------+
     |       БЛОГ (/blog)          |                 |   БАЗА ЗНАНИЙ (/knowledge)   |
     +-----------------------------+                 +-----------------------------+
     | • Смыслы, тренды, визионерство|               | • Инженерные промпты (1-click)|
     | • Большие лонгриды и кейсы  |                 | • Архитектуры AI-агентов    |
     | • Мышление фаундера         |                 | • Рецепты Vibe Coding       |
     | • Входная воронка и SEO     |                 | • Фреймворки трекинга (HADI)|
     +--------------+--------------+                 +--------------+--------------+
                    |                                               |
                    +-----------------------+-----------------------+
                                            |
                                            v
                    +-----------------------------------------+
                    |      КОНВЕРСИЯ В ПРОДУКТЫ И КЛУБ        |
                    |  (Клуб Tribute · Трекинг · Менторинг)   |
                    +-----------------------------------------+
```

### Сравнительная матрица:

| Параметр | 📝 Блог (`/blog`) | 🧠 База Знаний (`/knowledge`) |
| :--- | :--- | :--- |
| **Главная цель** | Привлечь внимание, доказать глубокую экспертизу, сформировать доверие, раскрыть методологию. | Дать моментальную прикладную пользу: готовый промпт, кусок рабочего кода, схему архитектуры. |
| **Формат контента** | Статьи, аналитические эссе, пошаговые кейсы, разборы трендов (1500–4000 слов). | Модульные карточки, сниппеты, промпты с кнопкой `[Скопировать]`, схемы в ASCII/Mermaid. |
| **Поведение читателя** | Вдумчивое чтение за чашкой кофе, шеринг в соцсетях и Telegram. | Рабочий инструмент: «нашел ➔ скопировал ➔ внедрил в свой проект за 5 минут». |
| **SEO / GEO эффект** | Попадание в информационные запросы Яндекса / Google. | Индексация в прямых ответах **ChatGPT, Perplexity, Claude и Gemini** по техническим запросам. |
| **Модель доступа** | 100% открыто и бесплатно. | **Freemium:** Базовые сниппеты открыты (SEO) ➔ Продвинутые пайплайны доступны по подписке Клуба. |

## 2. Архитектура Блога (`/blog`)

### 2.1. Рубрикатор статей (4 ключевых потока):
1. **`// VIBE CODING & РАЗРАБОТКА`**
   - Скоростная разработка сервисов без раздутых бюджетов и многомесячных согласований.
   - Стек инструментов (Claude Code, Cursor, Antigravity, Supabase, Next.js, Nginx).
   - Как фаундеру без навыков программирования собрать работающий MVP за 3 дня.
2. **`// ПРИКЛАДНЫЕ ИИ-АГЕНТЫ`**
   - Автономные конвейеры (генерация медиа, автодокументооборот, парсинг данных).
   - Интеграция LLM с CRM-системами (Bitrix24 / amoCRM) и Telegram-мостами.
   - Разбор реальных сценариев роботизации отделов продаж и клиентской поддержки.
3. **`// ТРЕКИНГ & ВЕНЧУР`**
   - Выход из операционки: как перестать тушить пожары и заняться масштабированием.
   - Теория ограничений (TOC) Голдратта в малом и среднем бизнесе.
   - Подготовка стартапа к инвестициям: метрики, питч-деки, воронка инвесторов.
4. **`// КЕЙСЫ & РАЗБОРЫ ОШИБОК`**
   - Анатомия запуска проектов (`aipsy.press`, `picozon.pro`, `maikers.pro`).
   - Разборы реальных бизнес-ситуаций клиентов (с цифрами до/после).

### 2.2. Страница со списком статей (`/blog`):
- **Hero-блок:** Заголовок *«Практика Vibe Coding, автономные агенты и трекинг стартапов»* + мгновенный поиск.
- **Табы фильтрации:** `Все` / `Vibe Coding` / `ИИ-Агенты` / `Трекинг` / `Кейсы`.
- **Featured Article (Главный материал месяца):** Крупная карточка с тегом, временем чтения и аннотацией.
- **Сетка статей (Grid 3):** Карточки в строгом стиле Swiss Stark:  
  `Тег рубрики` ➔ `Дата публикации` ➔ `Заголовок H3` ➔ `Краткий лид` ➔ `Время чтения` ➔ `Кнопка «Читать →»`.
- **Подвал списка:** Блок подписки на Telegram-канал `@uncrn_sage` для анонсов новых статей.

### 2.3. Анатомия страницы статьи (`/blog/slug-name`):
- **Хлебные крошки:** `Главная / Блог / Название рубрики / Заголовок статьи`.
- **Шапка статьи:** Тег рубрики, дата, время чтения, кнопка «Поделиться в Telegram».
- **Заголовок H1** + авторский блок (Михаил Пузырёв, аватар, ссылка на Telegram).
- **Содержание (Table of Contents):** Плавающее боковое меню по заголовкам статьи (Scrollspy).
- **Тело статьи:**
  - Крупная типографика (Space Grotesk + чистый интерлиньяж).
  - Выделенные акцентные цитаты (*Callouts* в рамках с изумрудным маркером).
  - Блоки кода с кнопкой копирования и подсветкой синтаксиса (JetBrains Mono).
  - Интерактивные схемы и инфографика.
- **Инлайн-лидмагнит:** Баннер в середине или конце статьи:  
  *«Хотите внедрить похожую архитектуру в свой бизнес? ➔ [Забронировать 30-мин разбор] или [Вступить в Клуб]»*.
- **Блок «Следующая статья»** + релевантные материалы из этой же рубрики.

## 3. Архитектура Базы Знаний (`/knowledge`)

База Знаний проектируется как **высокотехнологичный хаб готовых решений** (в духе Raycast Store или Cursor Directory).

### 3.1. Структура 4 разделов Базы Знаний:

```
├── 01. СИСТЕМНЫЕ ПРОМПТЫ (Prompt Engineering)
│   ├── B2B-продажи: Квалификация по SPIN, ответы на возражения, холодный аутрич
│   ├── Маркетинг: Анализ конкурентов, генерация смысловых воронок, тексты лендингов
│   ├── Разработка: Системные промпты для Claude 3.7 / Gemini Pro, архитектурные промпты
│   └── Аналитика: Промпты для извлечения сущностей из транскриптов и таблиц
│
├── 02. АРХИТЕКТУРЫ АГЕНТОВ (AI Agent Blueprints)
│   ├── Telegram-бот суммаризации аудио и PDF с отправкой в Notion/CRM
│   ├── Автоматический парсер Telegram-каналов с LLM-фильтрацией лидов
│   ├── Связка Webhook ➔ Claude API ➔ Bitrix24 сделка + генерация счета
│   └── Фабрика контента: парсер трендов ➔ генерация статьи ➔ публикация в WordPress/Webflow
│
├── 03. РЕЦЕПТЫ VIBE CODING (Code & Stack Snippets)
│   ├── Шаблон чистого Nginx конфига с SSL, Gzip и 301 редиректами
│   ├── Подключение Yandex Metrika с 0ms задержкой и авто-целями
│   ├── Интеграция оплат (Tribute API, ЮKassa, CloudPayments)
│   └── Подключение базы данных Supabase / PostgreSQL к статическому сайту
│
└── 04. ФРЕЙМВОРКИ ТРЕКИНГА (Business Frameworks)
    ├── Шаблон трекшн-карты HADI-спринтов (Google Sheets / Notion)
    ├── Калькулятор Юнит-экономики (CAC, LTV, Churn, C1/C2)
    ├── Чек-лист упаковки стартапа перед питчем инвестору
    └── Матрица снятия ограничений по теории Голдратта (TOC)
```

### 3.2. Интерфейс карточки знания:
Каждая единица знания — это модульная карточка с метаданными:
- **Бейдж категории:** `[ПРОМПТ]`, `[СНИППЕТ]`, `[АРХИТЕКТУРА]`, `[ШАБЛОН]`.
- **Бейдж совместимости:** `[Claude 3.7]`, `[GPT-4o]`, `[Bitrix24]`, `[Node.js]`, `[Make/n8n]`.
- **Сложность:** `Легко` / `Средне` / `Продвинутый`.
- **Кнопка «Быстрое копирование»:** В 1 клик копирует промпт или скрипт в буфер обмена.
- **Статус доступа:**  
  - 🟢 `[OPEN SOURCE / FREE]` — доступно всем сразу.  
  - 🔒 `[CLUB EXCLUSIVE]` — доступ по подписке Клуба (кнопка *«Разблокировать через Tribute ↗»*).

## 5. Технический Стек для Реализации (будущий этап)

1. **Формат хранения контента:** Легковесные Markdown-файлы (`.md`) с Frontmatter-метаданными (заголовок, дата, теги, превью).
2. **Сверхбыстрая генерация:** Генерация статических чистых HTML-страниц без тяжелых CMS (сохраняет скорость сайта 100/100 и отклик сервера < 50ms).
3. **GEO & Schema.org:** Автоматическая генерация разметки `Schema.org/TechArticle` и динамическое дополнение `sitemap.xml` и `llms.txt` при публикации каждого нового материала.
