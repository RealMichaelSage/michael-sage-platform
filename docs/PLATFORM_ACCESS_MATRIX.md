## 1. Уровни доступа в&nbsp;системе

На&nbsp;платформе действует 3 четких уровня доступа:

1. **Публичный доступ (Все посетители):** доступен абсолютно любому пользователю интернета без&nbsp;регистрации и&nbsp;авторизации.
2. **Зарегистрированные пользователи (Пользователи платформы):** пользователи, прошедшие быструю бесплатную авторизацию через Telegram OAuth и&nbsp;получившие персональный Личный кабинет (`/cabinet/`).
3. **Резиденты Клуба (SAGE Neuro Family):** участники с&nbsp;активной платной подпиской в&nbsp;биллинге Tribute (1 900 ₽ первый месяц, далее 1 500 ₽/мес) либо ученики персонального наставничества Михаила Пузырёва. Имеют бейдж `💎 ДОСТУП РЕЗИДЕНТА АКТИВЕН` и&nbsp;полный доступ ко&nbsp;всем закрытым материалам.

## 3. Подробное описание доступа по&nbsp;группам

### 1. Публичный доступ (Для&nbsp;всех посетителей без&nbsp;авторизации)
Любой пользователь может свободно изучать:
- **Базу Знаний платформы:** интерактивный глоссарий (120+ терминов), библиотеку системных ролевых промптов (37 ролей), подробные white paper по&nbsp;агентам и&nbsp;гайды по&nbsp;оплате зарубежных AI-подписок.
- **Интерактивные расчетные инструменты:** венчурную финансовую модель 5.0 Pro с&nbsp;выгрузкой в&nbsp;Excel и&nbsp;калькулятор налогов/наценки.
- **Атлас решений:** 51 готовый архитектурный сценарий для&nbsp;автоматизации маркетинга, продаж, HR и&nbsp;операционки.
- **Открытые интерактивные лекции и&nbsp;программы курсов:** материалы по&nbsp;вайб-кодингу, автоматизации и&nbsp;детскому курсу AI-Старт.
- **Страницы услуг, бронирования и&nbsp;юридические документы:** бронь слотов в&nbsp;календаре, оферта клуба, политика конфиденциальности.

### 2. Зарегистрированные пользователи (Авторизация через Telegram OAuth)
После входа по&nbsp;кнопке Telegram в&nbsp;шапке сайта пользователю открывается Личный кабинет (`/cabinet/`):
- **Интерактивные шпаргалки:** встроенное модальное окно с&nbsp;20 схемами профессионального освещения и&nbsp;20 ракурсами съемки для&nbsp;нейрофотосессий с&nbsp;готовыми промптами.
- **Каталог участников (`/cabinet/?tab=members`):** просмотр карточек других зарегистрированных участников и&nbsp;резидентов (при&nbsp;условии, что&nbsp;пользователь сам открыл видимость своего профиля).
- **Витрина сервисов (`/cabinet/?tab=solutions`):** централизованный доступ к&nbsp;Sagemeet и&nbsp;SAGE VPN.
- **Персональное «Избранное» (`/cabinet/?tab=favorites`):** сохранение полезных материалов со&nbsp;звездочкой.
- **Настройки профиля:** заполнение визитки, контактов Telegram, ссылок на&nbsp;блог/сайт, тумблер приватности.
- **Вкладка «Закрытый Клуб» (`/cabinet/?tab=club`):** просмотр подробной программы, расписания созвонов и&nbsp;кнопка вступления в&nbsp;сообщество.

### 3. Резиденты Клуба (Активная подписка SAGE Neuro Family / Ученики наставничества)
Обладают наивысшим статусом на&nbsp;платформе и&nbsp;эксклюзивными материалами:
- **Закрытый видеоархив (`/cabinet/?tab=education`):** просмотр 6 полноценных практических мастер-классов и&nbsp;воркшопов через встроенный видеоплеер (Kinescope / VK Video) без&nbsp;рекламы и&nbsp;ограничений.
- **Закрытый Telegram-чат SAGE Neuro Family:** прямое участие в&nbsp;комьюнити практиков, обмен опытом, нетворкинг с&nbsp;предпринимателями и&nbsp;разработчиками.
- **Регулярные живые созвоны:** мастермайнды по&nbsp;четвергам (разбор кода, AI-агенты, Antigravity) и&nbsp;венчурные дайджесты по&nbsp;воскресеньям.
- **Личная обратная связь:** код-ревью, разбор гипотез и&nbsp;советы напрямую от&nbsp;Михаила Пузырёва.
- **Статус резидента:** плашка `💎 ДОСТУП РЕЗИДЕНТА АКТИВЕН` в&nbsp;профиле и&nbsp;выделенный бейдж в&nbsp;общем каталоге участников.
- **Специальные условия:** приоритет и&nbsp;квоты на&nbsp;использование сервисов платформы.
